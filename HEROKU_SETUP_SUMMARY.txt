🏗️  ARCHITECTURE

Your Heroku app runs TWO separate processes:

┌──────────────────────────────────────────────────────────┐
│  Heroku App: njangi-on-chain                             │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  WEB PROCESS (Port 3000)          BOT PROCESS (Port 3001)│
│  ├─ Next.js Frontend             ├─ Node.js Backend     │
│  ├─ Admin Dashboard              ├─ Event Listener      │
│  ├─ /api/whatsapp/* endpoints    ├─ Message Sender      │
│  └─ WhatsApp Webhooks            └─ Blockchain Events   │
│                                                          │
└──────────────────────────────────────────────────────────┘

Both processes share the SAME environment variables (set in Heroku Config)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔑 KEY POINTS

1. Environment Variables
   • Frontend uses: NEXT_PUBLIC_* (browser accessible)
   • Backend uses: ALL variables (server only)
   • Both use: Shared Heroku Config Vars

2. Procfile Already Configured
   • web: npm start (Next.js)
   • bot: cd whatsapp-bot-backend && npm start (Node.js)
   • Both processes start automatically on deployment

3. WhatsApp Webhook Flow
   WhatsApp Cloud → POST https://njangi-on-chain.herokuapp.com/api/whatsapp/webhook
   ↓
   Heroku Router → web dyno (port 3000)
   ↓
   Next.js API handler → /api/whatsapp/webhook.ts
   ↓
   Processes webhook, stores/queues message
   ↓
   Bot process (async) picks up from queue

📊 VARIABLE ORGANIZATION

ENVIRONMENT VARIABLES ARE ORGANIZED IN 3 CATEGORIES:

1. PUBLIC VARIABLES (in browser)
   • NEXT_PUBLIC_TESTNET_RPC_URL
   • NEXT_PUBLIC_MAINNET_RPC_URL
   • NEXT_PUBLIC_*_PACKAGE_ID
   • NEXT_PUBLIC_*_WHATSAPP_*
   • NEXT_PUBLIC_*_ENOKI
   • NEXT_PUBLIC_ZKLOGIN_*_CLIENT_ID

2. SERVER VARIABLES (backend only)
   • ZKLOGIN_*_ENOKI_KEY
   • ZKLOGIN_*_CLIENT_SECRET
   • WHATSAPP_*
   • NODE_ENV
   • LOG_LEVEL

3. SHARED VARIABLES (both use same value)
   • RPC URLs
   • Package IDs
   • Enoki keys

⚡ TROUBLESHOOTING QUICK REFERENCE

Bot won't start?
  → Check: WHATSAPP_PHONE_NUMBER_ID, WHATSAPP_ACCESS_TOKEN, ZKLOGIN_*_ENOKI_KEY
  → Run: heroku logs -a njangi-on-chain --dyno=bot --tail

Webhook not receiving messages?
  → Verify: Callback URL matches exactly in WhatsApp dashboard
  → Check: WHATSAPP_VERIFY_TOKEN matches
  → Resend subscription in WhatsApp dashboard

Variables not loading?
  → Check: heroku config:get VARIABLE_NAME -a njangi-on-chain
  → Set: heroku config:set VARIABLE_NAME=value -a njangi-on-chain

Both processes failing?
  → Check both logs: heroku logs -a njangi-on-chain --tail
  → Common: Missing .env variables
  → Fix: Set all required variables, then redeploy
