PART 3: HEROKU BUILD & DEPLOYMENT
═════════════════════════════════════════════════════════════════════════════════

Heroku Build Process
│
├─ Parse Procfile
│  ├─ web: npm start
│  └─ bot: cd whatsapp-bot-backend && npm start
│
├─ Install Dependencies
│  ├─ Root: npm install (Next.js, dependencies)
│  └─ Bot: cd whatsapp-bot-backend && npm install
│
├─ Build
│  ├─ Next.js: Build optimized bundle
│  └─ Bot: Compile TypeScript
│
├─ Launch Processes
│  ├─ web dyno → npm start (port 3000)
│  └─ bot dyno → npm start (port 3001)
│
└─ Read Environment Variables
   └─ All processes get Heroku Config Vars


PART 4: RUNTIME - WHATSAPP WEBHOOK FLOW
═════════════════════════════════════════════════════════════════════════════════

User sends WhatsApp Message
        ↓
Meta WhatsApp Cloud API
        ↓
Detects webhook configured for app
        ↓
Makes POST request to:
https://njangi-on-chain.herokuapp.com/api/whatsapp/webhook
        ↓
Heroku Load Balancer
        ↓
Routes to "web" dyno (Next.js, port 3000)
        ↓
Next.js API Handler
/api/whatsapp/webhook.ts
        ├─ Verify webhook signature (HMAC)
        ├─ Parse incoming message
        ├─ Store in message queue
        └─ Return 200 OK
        ↓
Bot Process (async)
/whatsapp-bot-backend
        ├─ Read from message queue
        ├─ Call Sui blockchain (fetch account data, etc)
        ├─ Generate response message
        ├─ Send via WhatsApp API
        ├─ Track delivery status
        └─ Store analytics


PART 5: RUNTIME - BOT BACKGROUND TASKS
═════════════════════════════════════════════════════════════════════════════════

Bot Process Running Continuously
├─ Event Listener (every N seconds)
│  ├─ Query Sui blockchain for events
│  ├─ Filter for circle-related events
│  └─ Queue messages to send
│
├─ Message Processor
│  ├─ Pick message from queue
│  ├─ Process through template engine
│  └─ Add action links
│
├─ WhatsApp Sender
│  ├─ Send via Meta Cloud API
│  ├─ Track delivery status
│  └─ Retry on failure
│
└─ Analytics
   └─ Track message metrics

═════════════════════════════════════════════════════════════════════════════════

                         Heroku Router
                              ↓
                    ┌─────────────────────┐
                    │  Load Balancer      │

                             │
                ┌────────────┴────────────┐
                ↓                         ↓
        ┌──────────────┐        ┌──────────────┐
        │  Web Dyno    │        │  Bot Dyno    │
        │  (Scaling)   │        │  (Scaling)   │
        ├──────────────┤        ├──────────────┤
        │ Next.js      │        │ Node.js      │
        │ Port 3000    │        │ Port 3001    │
        │              │        │              │
        │ • Webhooks   │        │ • Listener   │
        │ • API Routes │        │ • Processor  │

        │ • Admin UI   │        │ • Analytics  │
        └──────────────┘        └──────────────┘
        
        (Each can be scaled independently)
        
        Example:
        heroku ps:scale web=2 bot=3
